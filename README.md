# Satuarb Portfolio

**https://satuarb.dev**

Glassmorphism portfolio website with Three.js 3D graphics, smooth animations, and project showcase.

## Features

- **Three.js 3D** — Rotating icosahedron with particles + mouse parallax
- **Glassmorphism** — Blur, gradient borders, glow effects
- **34 Projects** — Filterable by category (Cyber Security, AI/ML, Analytics, DevOps, Games, Web)
- **Hover Effects** — Tilt, description reveal, glow
- **Animated Counters** — Stats that animate on scroll
- **Loading Screen** — Animated spinner
- **Mobile Responsive** — 360px to 1440px
- **Smooth Scroll** — Navigation with active highlighting

## Tech Stack

- HTML5
- CSS3 (Glassmorphism, animations)
- JavaScript (Vanilla)
- Three.js (3D graphics)
- Google Fonts (Inter, JetBrains Mono)

## Deploy

### Netlify
1. Drag & drop this folder to [app.netlify.com/drop](https://app.netlify.com/drop)

### Vercel
```bash
vercel deploy
```

### Any Web Server
Just upload all files to your web server.

## Local Development

```bash
# Python
python -m http.server 8000

# Node
npx serve .

# Then open http://localhost:8000
```
